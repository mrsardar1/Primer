# Primer

A cross-platform mobile app that gives users personalized guidance for skin, hair, makeup, color analysis, and wardrobe from a single photo. Live on the **App Store** and **Google Play** with paying subscribers.

> Built and shipped solo as sole engineer and founder.

---

## What It Does

Users scan their face once and receive:
- Skin type analysis and personalized skincare routine
- Deep dermatological scan with concern identification
- Seasonal color palette analysis
- Hair and makeup routine recommendations
- Daily outfit suggestions generated from their own catalogued wardrobe
- Product ingredient compatibility checks before buying
- Weekly progress tracking with photo check-ins and trend scoring

---

## Technical Highlights

- **6 AI-powered vision analysis pipelines** — skin, deep derm, color season, hair, makeup, and product compatibility
- **Custom i18n system** supporting 21 languages including RTL — built without external dependencies
- **Full-stack backend** using Supabase (PostgreSQL, Row Level Security, Auth, Storage)
- **Subscription monetization** via Apple StoreKit and Google Play Billing APIs
